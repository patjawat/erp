# HR engagement MVP

เพิ่มแบบสอบถามแบบมีเวอร์ชัน รอบสำรวจ รายชื่อผู้มีสิทธิ์ ณ วันเปิดรอบ การตอบผ่านบัญชี ERP ผลรวมและกราฟ แผนปรับปรุง และการส่งออกผลรวม ในตาราง `hr_engagement_*` 13 ตาราง

## ติดตั้งและเข้าถึง

รัน `php yii migrate/up --migrationPath=@app/migrations/engagement` บนระบบเป้าหมายก่อนใช้งาน ติดตั้งในเครื่องพัฒนาแล้ว ไม่มีการเปิดสำรวจจริงโดยอัตโนมัติ

- `/hr/engagement/templates`: สร้างและเผยแพร่แบบสอบถาม
- `/hr/engagement/index`: กำหนดรอบ นโยบาย และเปิดรับคำตอบ
- `/hr/engagement/mine`: แบบสำรวจของบุคลากรที่เข้าสู่ระบบ
- `/hr/engagement/report`: ผลรวมและกราฟ
- `/hr/engagement/actions`: แผนปรับปรุงและติดตามผล

กำหนดสิทธิ์ `engagementManageTemplate`, `engagementManageRound`, `engagementViewAnalytics`, `engagementManageAction`, `engagementExportAggregate` ตามหน้าที่ Migration สร้างสิทธิ์แต่ไม่แจกให้ผู้ใช้ อนุญาตผู้มีสิทธิ์ `admin` ตามระบบเดิม

## ขอบเขตและความลับ

MVP แสดงภาพรวมองค์กร ใช้คำถามทิศทางบวก 1–5 และตัวเลือกไม่ประสงค์ตอบ น้ำหนักเท่ากัน คะแนนรวมใช้ด้านผลความผูกพัน ปัจจัยสนับสนุนแสดงแยก ไม่ใช้ตัวกรองประชากรของ dashboard กรองผลสำรวจ ปกปิดผลที่จำนวนผู้ตอบใช้คำนวณต่ำกว่าเกณฑ์อย่างน้อย 5 คน ข้อมูลไม่ครบแสดงสถานะแทนศูนย์

เป็นข้อมูลลับที่ยังเชื่อมสิทธิ์บุคลากรได้ ไม่ใช่แบบไม่ระบุตัวตนอย่างสมบูรณ์ ปิดการเก็บ payload และบริบทผู้ใช้ใน Yii log/debug สำหรับหน้าตอบ ต้องตั้งค่า proxy/APM ไม่บันทึกเนื้อหาคำตอบด้วย

ตรวจรายการครบอายุด้วย `php yii engagement/retention` (อ่านอย่างเดียว) ผู้ดูแลเซิร์ฟเวอร์ดำเนินการลบข้อมูลดิบด้วย `php yii engagement/retention --apply=1 --reason="retention policy"` หลังตรวจรายการ คงผลรวมและแผนปรับปรุงไว้ ยังไม่ตั้งงานตามเวลาอัตโนมัติ ต้องกำหนดการจัดการสำรองข้อมูลตามนโยบายแยกด้วย

การเชื่อม Task, ใบยืนยันการตอบกับ Appreciation, eNPS, ข้อความอิสระ และการวิเคราะห์รายหน่วยงาน เป็นงานระยะถัดไป ลิงก์เข้าแบบสำรวจไม่เปลี่ยนสถานะกิจกรรม Appreciation

## การตรวจสอบ

`php tests/hr-engagement-integration.php` ผ่าน 44 รายการด้วย SQLite ในหน่วยความจำและข้อมูลสังเคราะห์ ทดสอบสูตร การส่งซ้ำ สิทธิ์ผู้ตอบ การปกปิดข้อมูล และ retention ตรวจคำสั่งล็อกแถว MySQL สำหรับแบบเวอร์ชัน 1 ผ่านโดย rollback และไม่เปลี่ยนข้อมูล แก้การสูญเสีย bindings เมื่อเพิ่ม `FOR UPDATE` แล้ว

การตรวจหน้าจอและสิทธิ์แบบ end-to-end ยังไม่ครบ ต้องทดสอบกลุ่มนำร่องและให้งาน HR ยืนยันคำถามและนโยบายก่อนเปิดใช้จริง การติดตั้งเครื่องพัฒนาไม่ใช่การ deploy production
