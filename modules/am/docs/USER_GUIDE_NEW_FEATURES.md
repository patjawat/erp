# คู่มือการใช้งานระบบบริหารทรัพย์สิน (ส่วนที่พัฒนาขึ้นใหม่)

เอกสารนี้อธิบายการใช้งานฟีเจอร์ที่เพิ่มเข้ามาในระบบบริหารทรัพย์สิน (Asset Management) โดยไม่ไปยุ่งกับระบบเดิม

---

## 1. ค่าเสื่อมราคา (ชุดใหม่)

การคำนวณค่าเสื่อมอิง **อายุการใช้งาน (ปี)** และ **มูลค่าซาก** จากฟอร์มครุภัณฑ์ — ไม่ใช้ข้อมูลค่าเสื่อมชุดเก่า (service_life / depreciation ใน data_json)

### เข้าหน้าค่าเสื่อมชุดใหม่

- จาก **หน้ารายละเอียดครุภัณฑ์** (ครุภัณฑ์ → เลือกรายการ) ให้กดปุ่ม **「ค่าเสื่อม (ชุดใหม่)」** ใต้รายละเอียดการ์ด
- หรือเข้าโดยตรง: **เมนู AM → ครุภัณฑ์ → เลือกรายการ → ค่าเสื่อม (ชุดใหม่)**  
  URL: `/am/equip/depreciation-v2?id=<รหัสครุภัณฑ์>`

### ข้อมูลที่ต้องมีในครุภัณฑ์

ใน **ฟอร์มแก้ไขครุภัณฑ์** ต้องกรอก:

- **อายุการใช้งาน (ปี)** (ฟิลด์ useful_life)
- **มูลค่าซาก** (ฟิลด์ residual_value) — ถ้าไม่มีให้ใส่ 0
- **วิธีคำนวณ** (depreciation_method) — ปัจจุบันใช้วิธีเส้นตรง

ถ้ายังไม่กรอก หน้านี้จะแสดงข้อความแจ้งให้ไปกรอกในฟอร์มแก้ไขก่อน

### สิ่งที่หน้านี้แสดง

- สรุป: ราคาทุน, วันที่รับเข้า, อายุการใช้งาน, มูลค่าซาก, วิธีคำนวณ, ค่าเสื่อมต่อปี/ต่อเดือน
- ตารางรายปี (พ.ศ.): มูลค่าต้นปี, ค่าเสื่อมประจำปี, ค่าเสื่อมสะสม, มูลค่าปลายปี

### พิมพ์ค่าเสื่อม

กดปุ่ม **「พิมพ์ค่าเสื่อม」** มุมขวาบน แล้วใช้ **พิมพ์** หรือ **Save as PDF** ของเบราว์เซอร์

---

## 2. รับครุภัณฑ์ทีละหลายรายการ (Bulk Create)

สร้างครุภัณฑ์หลายรายการในครั้งเดียวจากแม่แบบและจำนวน (รองรับการวางเลข Serial หรืออัปโหลด CSV)

### เข้าหน้า

- **URL:** `/am/asset/bulk-create`  
  หรือจากเมนูระบบบริหารทรัพย์สิน → ลิงก์ไป **รับครุภัณฑ์แบบกลุ่ม** (ถ้ามีในเมนู)

### ขั้นตอนโดยย่อ

1. **ขั้นที่ 1** — ข้อมูลการจัดซื้อ/รับเข้า (ตามที่ฟอร์มกำหนด)
2. **ขั้นที่ 2** — เลือก **รายการครุภัณฑ์** (ทะเบียนรหัสทรัพย์สิน) จากปุ่มค้นหา
3. **ขั้นที่ 3** — ระบุ **จำนวน** (1–500) และเลือกหนึ่งอย่าง:
   - **วางรายการ Serial/หมายเลข** ในช่องข้อความ (บรรทัดละ 1 รายการ)  
   - หรือ **อัปโหลดไฟล์ CSV** ที่มีรายการต่อบรรทัด
4. **ขั้นที่ 4** — ตรวจสอบรายการที่ระบบสร้าง แล้วกดบันทึก

ระบบจะสร้างครุภัณฑ์ตามจำนวนและรายการที่กรอก (ใช้ transaction ไม่บันทึกครึ่งทาง)

---

## 3. พิมพ์ QR Code ครุภัณฑ์

QR แต่ละใบจะเก็บ **หมายเลขครุภัณฑ์ (asset_number/code)** เพื่อใช้สแกนเปิดดูข้อมูลในระบบ

### เข้าหน้า

- **URL:** `/am/asset/print-qr`  
  หรือจากเมนู/ปุ่ม **「พิมพ์ QR」** ในระบบบริหารทรัพย์สิน

### วิธีใช้

1. ใส่ **รหัส ID ครุภัณฑ์** ในช่อง (คั่นด้วย comma) เช่น `1,2,3`
2. กด **แสดงสติกเกอร์**
3. เมื่อเห็นสติกเกอร์แล้ว กด **「พิมพ์」** เพื่อพิมพ์หรือ Save as PDF

สามารถเลือกครุภัณฑ์จากหน้ารายการครุภัณฑ์แล้วส่ง IDs มาหน้านี้ได้ (ขึ้นกับเมนูที่ออกแบบ)

## 4. วงจรชีวิตครุภัณฑ์ (โอนย้าย / ส่งซ่อม / จำหน่าย)

การโอนย้าย ส่งซ่อม และจำหน่ายจะบันทึกทั้งใน **ประวัติวงจรชีวิตเดิม** และในตาราง **am_asset_transactions** (สำหรับรายงานการเคลื่อนย้าย)

### โอนย้าย

- **URL:** `/am/asset/transfer`  
  หรือจากหน้ารายละเอียดครุภัณฑ์ → **โอนย้าย**
- กรอก: สถานที่ใหม่, หน่วยงานใหม่, หมายเหตุ แล้วบันทึก

### ส่งซ่อม

- **URL:** `/am/asset/repair`  
  หรือจากหน้ารายละเอียดครุภัณฑ์ → **ส่งซ่อม**
- กรอก: วันที่ซ่อม, ปัญหา/รายละเอียด, ค่าซ่อม, ผู้ให้บริการ (ถ้ามี) แล้วบันทึก  
  สถานะครุภัณฑ์จะเปลี่ยนเป็น **ส่งซ่อม**
- เมื่อซ่อมเสร็จ: ใช้ **รับคืนจากซ่อม** (Return) เพื่อเปลี่ยนสถานะกลับเป็น **ใช้งานได้**

### จำหน่าย

- **URL:** `/am/asset/dispose`  
  หรือจากหน้ารายละเอียดครุภัณฑ์ → **จำหน่าย**
- กรอก: วิธีจำหน่าย, วันที่จำหน่าย, หมายเหตุ แล้วบันทึก  
  สถานะครุภัณฑ์จะเปลี่ยนเป็น **จำหน่าย**

## 5. รายงาน (Reports)

มี 4 รายงานหลัก รองรับ **Export CSV** (เปิดใน Excel ได้) โดยกดปุ่ม **「Export CSV」** ในแต่ละหน้ารายงาน

### 5.1 รายงานทะเบียนครุภัณฑ์ (Asset Register)

- **URL:** `/am/report/register`
- แสดงรายการครุภัณฑ์ตามตัวกรอง (กลุ่ม/ประเภท/หน่วยงาน ฯลฯ)
- คอลัมน์: รหัส, ชื่อ, ประเภท, หน่วยงาน, วันที่รับ, ราคา, สถานะ
- **Export:** กด **Export CSV** เพื่อดาวน์โหลดไฟล์ CSV (ใช้เปิดใน Excel ได้)

### 5.2 รายงานค่าเสื่อม (ชุดใหม่)

- **URL:** `/am/report/depreciation-report`
- แสดงครุภัณฑ์ที่มีอายุการใช้งานและมูลค่าซาก พร้อมค่าเสื่อมต่อปีที่คำนวณได้
- คอลัมน์: รหัส, ชื่อ, ราคาทุน, มูลค่าซาก, อายุ(ปี), ค่าเสื่อม/ปี, วันที่รับ
- **Export:** กด **Export CSV**

### 5.3 รายงานการเคลื่อนย้าย (Movement)

- **URL:** `/am/report/movement-report`
- แสดงประวัติการโอนย้าย/ซ่อม/จำหน่ายจากตาราง **am_asset_transactions**
- คอลัมน์: รหัสครุภัณฑ์, ประเภท, จาก/ถึงสถานที่, จาก/ถึงหน่วยงาน, หมายเหตุ, วันที่
- **Export:** กด **Export CSV**

### 5.4 รายงานสำรวจครุภัณฑ์ (Survey)

- **URL:** `/am/report/survey-report`
- แสดงผลการสำรวจจาก **am_asset_survey_items** (โครงการสำรวจจากโมดูล amSurvey)
- สามารถกรองตาม **โครงการสำรวจ** ได้
- คอลัมน์: โครงการสำรวจ, หมายเลขที่สแกน, สถานะ (พบ/ไม่พบ/ครุภัณฑ์ใหม่), สถานที่ตรง, หน่วยงานตรง, วิธีสำรวจ, วันเวลาสำรวจ
- **Export:** กด **Export CSV**

## 6. ภาพรวม (Dashboard)

- **URL:** `/am/dashboard` (หรือ `/am` แล้วเลือกภาพรวม ถ้าเมนูชี้มาที่นี่)

### สิ่งที่แสดง

- **ตัวชี้วัดหลัก (KPIs):** ครุภัณฑ์ทั้งหมด, เกินอายุการใช้งาน, ส่งซ่อม, รอจำหน่าย, มูลค่าโดยประมาณที่ต้องแทนที่
- **สถานะสุขภาพ:** ใช้งานดี, ใกล้ครบอายุ, ครบอายุแล้ว, ส่งซ่อม, รอจำหน่าย
- **การคาดการณ์การแทนที่:** จำนวนและมูลค่าโดยประมาณของครุภัณฑ์ที่ใกล้ครบอายุ (ภายใน 1–3–5 ปี)
- **กราฟ:** การกระจายตามประเภท, ตามหน่วยงาน, ตามอายุ
- **กิจกรรมล่าสุด:** โอนย้าย/ซ่อม/จำหน่ายล่าสุด

ข้อมูล Dashboard ถูก cache 5 นาที เพื่อความเร็วเมื่อมีครุภัณฑ์จำนวนมาก

## 7. ปิดปีค่าเสื่อม (Fiscal Year Closing)

ใช้สำหรับ **ปิดปีบัญชีค่าเสื่อม** — สร้างรายการค่าเสื่อมรายปีในตาราง **am_asset_depreciations** และล็อกไม่ให้แก้ไขปีที่ปิดแล้ว

### การใช้งาน (ฝั่งโปรแกรม)

ปัจจุบันยังไม่มีปุ่มในหน้าเว็บ — ต้องเรียกผ่านโค้ดหรือคำสั่ง console เช่น

```php
// ตัวอย่าง: ปิดปี พ.ศ. 2568 (ค.ศ. 2025)
\app\modules\am\services\DepreciationClosingService::closeYear(2025);
```

ผลลัพธ์:

- สร้างแถวใน **am_asset_depreciations** ตามครุภัณฑ์ที่กรอกอายุการใช้งาน/มูลค่าซากแล้ว
- บันทึกการปิดปีใน **am_depreciation_closings**
- ล็อกรายการค่าเสื่อมปีนั้น (is_locked = true)

หากต้องการให้มี **หน้าจอปิดปี** ในระบบ สามารถเพิ่ม action ในโมดูล am (เช่น หน้าเฉพาะสำหรับผู้ดูแล) แล้วเรียก `DepreciationClosingService::closeYear($year)` จากนั้นได้
