# โฟลว์การเบิกวัสดุคลังหลัก

โฟลว์มาตรฐานการเบิกวัสดุจากคลังหลักมีดังนี้

---

## ลำดับขั้นตอน (สรุป)

| ลำดับ | ขั้นตอน | หมายเหตุ |
|-------|---------|----------|
| 1 | **เขียนใบเบิก พร้อมเหตุผล** | หน่วยงาน/คลังย่อยสร้างใบขอเบิก ระบุเหตุผลหรือวัตถุประสงค์การเบิก รายการพัสดุและจำนวน แล้วส่งคำขอ |
| 2 | **หัวหน้าอนุมัติ (ระบบ Approve)** | หัวหน้ากดอนุมัติ → สถานะเปลี่ยนเป็น **APPROVED** *(หรือเจ้าหน้าที่คลังอนุมัติแทนได้)* ยังไม่ตัดสต็อก |
| 3 | **จ่ายวัสดุตาม FIFO** | เจ้าหน้าที่คลังไปที่เมนู "รายการจ่ายพัสดุ" → เลือกใบที่อนุมัติแล้ว → ดำเนินการจ่าย (เลือก Lot/จำนวน ระบบตัดสต็อกตาม FIFO) → ยืนยันจ่าย |
| 4 | **พิมพ์ใบเบิก** | หลังจ่ายแล้ว สามารถพิมพ์ใบเบิกหรือส่งออก PDF จากหน้ารายการจ่ายหรือจากใบที่ดำเนินการจ่ายแล้ว |

---

## รายละเอียดแต่ละขั้น

### 1. เขียนใบเบิก พร้อมเหตุผล

- **เมนู:** สร้างใบขอเบิก (`/inventory-v2/requisition/create`)
- **ผู้ทำ:** หน่วยงานที่ต้องการเบิก (คลังย่อย/หน่วยงาน)
- **รายการ:** เลือกคลังที่จ่ายของ, หน่วยงานที่รับของ, วันที่, **เหตุผล/วัตถุประสงค์การเบิก**, **ผู้เห็นชอบ (หัวหน้า)** — ระบุชื่อและตำแหน่งตอนสร้างใบเบิก, รายการพัสดุและจำนวน
- **ส่งคำขอ:** บันทึกแล้วส่งคำขอ → สถานะเป็น PENDING (รอหัวหน้าอนุมัติ)

### 2. หัวหน้าอนุมัติ (ระบบ Approve)

- **เมนู:** ทะเบียนใบขอเบิก (`/inventory-v2/requisition/index`) → กด **อนุมัติ** ที่ใบที่ต้องการ
- **ผู้ทำ:** หัวหน้า *(หรือเจ้าหน้าที่คลังอนุมัติแทนได้ ตามนโยบายหน่วยงาน)*
- **ผลลัพธ์:** สถานะเปลี่ยนเป็น **APPROVED** — ยังไม่ตัดสต็อก คลังจะจ่ายที่ขั้นตอนถัดไป

### 3. จ่ายวัสดุตาม FIFO

- **เมนู:** รายการจ่ายพัสดุ (`/inventory-v2/issue/index`) → เลือกใบที่สถานะ APPROVED → **ดำเนินการจ่าย**
- **ผู้ทำ:** เจ้าหน้าที่คลังหลัก
- **การทำงาน:** ระบบแสดงรายการพัสดุที่อนุมัติแล้ว เจ้าหน้าที่เลือก **Lot** และจำนวนที่จ่าย ระบบตัดสต็อกแบบ **FIFO** (ตัดจากรายการรับเข้าที่เก่าที่สุดใน Lot นั้นก่อน) แล้วยืนยันจ่าย → สถานะเปลี่ยนเป็น **CONFIRMED** และตัดสต็อกจริง

### 4. พิมพ์ใบเบิก

- **จาก:** หน้ารายการจ่ายพัสดุ หรือ หน้า "ดำเนินการจ่าย" ของใบนั้น
- **ปุ่ม:** พิมพ์ใบเบิก / ดาวน์โหลด PDF
- ใช้สำหรับลงนามและเก็บเป็นหลักฐาน (ผู้เบิก, ผู้จ่ายพัสดุ, ผู้เห็นชอบ, ผู้รับวัสดุ, ผู้สั่งจ่าย)

---

## สถานะเอกสาร (Status)

| สถานะ | ความหมาย |
|--------|----------|
| DRAFT | ฉบับร่าง ยังไม่ส่ง |
| PENDING | รอหัวหน้าอนุมัติ |
| **APPROVED** | อนุมัติแล้ว รอคลังจ่าย (ยังไม่ตัดสต็อก) |
| **CONFIRMED** | คลังจ่ายของแล้ว (ตัดสต็อกแล้ว) |
| CANCELLED | ยกเลิก |

---

*เอกสารนี้สอดคล้องกับ flow ใน `flow-requisition-issue.md` และการทำงานจริงใน RequisitionController, IssueController*
